# GreenRay---  Deployed Link
## Overview
This project is a web-based Solar Plant Monitoring Dashboard developed during my 
internship at **Green Ray Technologies Private Limited**. The application supports 
internal engineering and operations teams by providing plant-level visibility, secure 
access, and centralized site management.

## Key Features
- Role-based authentication (Admin & Engineer)
- Solar plant site management (Add, Edit, Update, Delete)
- Map-based visualization of solar plant locations
- Secure access to operational data
- Responsive dashboard interface

## My Contribution
- Developed backend logic using **Python (Flask)**
- Implemented role-based access control and authentication
- Built REST APIs for managing solar plant data
- Integrated map visualization for plant locations
- Participated in debugging, testing, and feature enhancements

## Tech Stack
- Frontend: HTML, CSS, JavaScript / React
- Backend: Python, Flask
- Database: SQLite
- Tools: Git, GitHub
